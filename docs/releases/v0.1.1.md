# SnapOCR 0.1.1（补丁版）

> 发布日期：2026-10-26
> 对比版本：v0.1.0（阶段二发布）
> 下载：[SnapOCR-0.1.1-win64.zip](https://github.com/poluce/SnapOCR/releases/download/v0.1.1/SnapOCR-0.1.1-win64.zip)（39,017,632 B）
> 产物：CI（Qt 6.10.3 + MSVC）windeployqt 绿色包，含 `translations/snapocr_en.qm`

## 修复

- **滚动长截图重复处理**：多次开始后完成一次会重复复制/重复写历史
  （`Qt::UniqueConnection` 对 lambda 无效导致重复连接）
- **长截图控制条被截进长图**：控制条现在保证不与截取区域相交（下方→上方→角落）
- **贴图窗关闭时的清理**：不再在对象析构回调里构造 `QPointer`
- 主题切换后自绘控件（标题栏/开关）不重绘的问题（v0.1.0 已含）

## 新增

### 拖拽导出（F-SYS-12）
- 覆盖层 **Ctrl+拖拽选区**、贴图窗 **Ctrl+拖拽**、截图历史缩略图直接拖出
- 同时提供文件 URL + PNG 位图 + 文本路径，兼容资源管理器/微信/Word/输入框
- 覆盖层拖拽的裁剪交给控制器完成，跨屏选区也不会漏屏

### 界面翻译骨架（i18n 基础版）
- `translations/snapocr_en.ts` + CMake `lrelease` 构建链，运行期从 exe 同级
  `translations/` 加载
- 设置面板新增「界面语言」（简体中文 / English，切换后重启生效）
- 首批文案已 `tr()` 化（主窗口入口、状态、标题栏按钮）

### 托盘
- 新增「贴图最近一张」：取历史最新一张直接贴到屏幕

## 改进

- 完成情况新增**需求追溯表**（62 项需求逐条状态与证据）
- 补齐边界回归测试：撤销/重做边界、无选中删除、空图元导出、命中越界、
  长截图单帧等 9 条
- 文档结构修正：完成情况章节重排、阶段二/三进展摘要、已知问题刷新
