## 0.2.1 更新内容

### 新增：在线更新（F-SYS-16）

- 启动后自动检查新版本（设置里可关闭），托盘菜单也可手动「检查更新」
- 发现新版本弹窗：版本号、安装包大小、更新说明，可选「下载并安装 / 稍后提醒 / 跳过此版本」
- 下载带进度条、可取消，校验文件大小
- 安装：提示"会关闭 SnapOCR，安装完成后自动重启"，随后静默安装并自动拉起新版本
- 更新源默认 GitHub Releases API；私有环境可在设置「更新源」填自定义 manifest
- 隐私：唯一联网点，仅检查/下载更新，无遥测、无账号

### 修复

- 发布包翻译瘦身：开发构建不再把 Qt 自带 34 个翻译文件带进发布包（包体 33.4MB → 31.8MB）
- 稳定性自检加固：打包版首跑偶发句柄 +12 误判为泄漏 → 预热 3 轮 + 以 **GDI 零增长**为泄漏主信号
  （句柄 ≤16 / USER ≤10 / 工作集 ≤96MB）

### 其他

- 英文翻译 119 → 154 条（新增更新相关文案，零缺失）
- 新增 CLI `--check-update [--update-feed URL]`（脚本/排障用）
- 仓库转为公开（2026-10-26），在线更新默认源可用

## 已验证（单机真机 + 自动化）

- 单测 39/39（新增更新解析 8 条、更新检查 5 条）
- `--selftest-all` 4/4、`--doctor`、`--stability-selftest` PASS（GDI 零增长）
- 在线更新端到端真机：弹「发现新版本」→ 下载 29,287,679 字节 → 确认安装 → 静默安装 →
  自动重启（日志：`update available` → `update downloaded` → 重启后注册热键）
- 公开仓库默认更新源实测：`--check-update` → `latest: 0.2.1`、安装包地址、`UP_TO_DATE`
- 真机 e2e：F1 截图 801×601、F4 OCR 已知文本、Esc 取消；英文界面/深色主题/单实例/历史/贴图窗
- 稳定性/性能：热键→遮罩 55–67ms、4K 捕获 55–57ms、OCR 88–91ms、空闲工作集 21–28MB

## 已知限制

- 多显示器矩阵（100%/125%/150%/200%、混合 DPI、负坐标、旋转、RDP、热插拔）未验证
- IM 剪贴板兼容（QQ/微信/钉钉/Word）未验证（测试机未安装这些应用）
- 干净 Windows 10/11 机器未验证
- 贴图组合键（R/Ctrl+T/Ctrl+E）、滚动长截图、放大镜取色为人工点测项
- RapidOCR（P1 延后）、代码签名（P2）、CLI 英文（P2）未做

## 包内容说明

- 绿色包含 `vc_redist.x64.exe`（缺 VC++ 运行库时手动运行）
- 已裁掉 Qt 的 DirectX 着色器编译器（`dxcompiler.dll`/`dxil.dll`，Widgets 用不到）

## 排障

```bat
SnapOCR.exe --doctor        :: 环境诊断（系统/DPI/显示器/OCR 语言/运行库/路径）
SnapOCR.exe --selftest-all  :: 冒烟/捕获/稳定性/性能汇总
SnapOCR.exe --check-update  :: 检查更新（可配 --update-feed）
```
