# SnapOCR 0.1.0（阶段二发布）

> 发布日期：2026-10-26
> 对比版本：v0.0.1（阶段一：截图 / 标注 / OCR / 热键托盘 / 设置 / 自启）
> 下载：[SnapOCR-0.1.0-win64.zip](https://github.com/poluce/SnapOCR/releases/download/v0.1.0/SnapOCR-0.1.0-win64.zip)
> 产物：CI（Qt 6.10.3 + MSVC）构建，windeployqt 绿色包，解压即可运行（含 VC++ 运行时）

## 新增功能

### 截图增强
- **延时截图**：1/2/3/5/10 秒倒计时，期间托盘提示并忽略重复触发
- **捕获鼠标光标**：设置项开关，颜色位图 + 掩码位图手工合成 alpha
- **放大镜 + 像素取色**：11×11 像素网格、中心准星、HEX/RGB 显示，按 `C` 复制 HEX
- **窗口识别**：悬停高亮窗口，单击直接选中该窗口区域（Z 序枚举，DWM 可见边框）
- **滚动长截图**：框选后点「滚动长截图」，自动按重叠区域拼接，页面到底自动结束
- **截图历史**：最近 50 张落盘、缩略图浏览、复制/贴图/另存为/删除

### 标注增强
- **模糊笔刷**：路径式高斯模糊（三次盒式模糊近似）
- **图元缩放 / 层级**：四角控制点缩放；`Ctrl+]`/`Ctrl+[` 上下移层，加 `Shift` 置顶/置底
- **填充 / 虚线**：工具条开关，虚线随线宽自适应
- **贴图**：置顶窗，拖动/滚轮缩放/Ctrl+滚轮透明度/R 旋转/Esc 关闭，右键菜单
- **复制后自动贴图**：设置项，默认关闭

### OCR 增强
- **段落合并**：`cleanText` 自动合并被排版拆断的行，可切回原始换行查看
- **失败提示与重试**：语言包缺失/选区太小/超时/贴边裁字分别给出可执行提示

### 系统
- **便携模式**：`SnapOCR.portable` 标记文件存在时，配置与日志都写到 exe 旁边

## 改进
- 主窗口与设置合并为单个窗口，即时生效；工具条单行化、浅色主题
- 离屏渲染测试基建（`QT_QPA_FONTDIR` 指定系统字体）与文档图自动产出
- e2e 冒烟改为向应用线程投递 `WM_HOTKEY`，不再注入键盘

## 已知问题 / 延后项
- `F-OCR-10` RapidOCR 引擎（ONNX Runtime + det/cls/rec 模型）**延后**：属 P1 可选项，
  需引入约 20MB+ 运行库与模型，计划在阶段三评估后单独立项。
- 阶段二新功能的真实交互点测（窗口识别悬停、滚动长截图、贴图拖动）需在解锁的桌面会话中补做；
  核心逻辑已由单测与离屏渲染覆盖。

## 升级说明
- 覆盖安装即可；配置项向后兼容（新增 `capture/detectWindows`、`editor/pinOnCopy`、
  `capture/includeCursor`、`capture/delaySeconds`，缺失时使用默认值）。
- 截图历史位于 `%LOCALAPPDATA%\poluce\SnapOCR\history`（便携模式为 `exe\history`）。

## 验证基线
- 单测：30 个测试套件全绿（ctest，offscreen）
- 冒烟：`SnapOCR.exe --smoke-test` PASS；`--capture-selftest` 输出
  `captureAll=58ms`、`region 120x80 (18ms)`（4K 单屏，DPR=2）
- CI：Windows / MSVC / Qt 6.10.3 构建 + ctest + 原生冒烟 + windeployqt 打包 artifact
