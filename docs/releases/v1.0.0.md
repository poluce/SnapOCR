## 这是什么

SnapOCR 是一款 Windows 10/11 上的轻量截图 + 标注 + OCR 工具：按下 `F1` 截图、标注后复制/保存，
按下 `F4` 框选取字并复制；托盘常驻、单实例、完全离线。

## 1.0.0 包含的能力

### 截图
- `F1` 全局热键（可配置，冲突检测并提示回退）、托盘菜单、`Ctrl+A` 全屏
- 冻结画面 + 选区外暗化、拖动/8 向缩放/方向键微调、尺寸坐标 HUD、窗口智能识别
- 延时截图（1–10s）、捕获鼠标光标（可选）、**放大镜 + 像素取色**
- **滚动长截图**（自动重叠拼接，失败给出提示）
- **截图历史**（最近 50 张，可重开编辑/复制/贴图/删除/清理）
- 多显示器、混合 DPI、负坐标；物理像素 1:1，不缩放不模糊

### 标注
- 矩形/椭圆/直线/箭头/画笔/文字/序号/高亮/马赛克/**高斯模糊笔刷**
- 选中移动删除、图元缩放控制点、层级调整、填充/虚线样式
- 撤销/重做（≥100 步）、颜色/线宽/字号
- `Ctrl+C` 复制（PNG+DIB）、`Ctrl+S` 保存 PNG/JPG（文件名模板、同名自动加序号）

### OCR（离线）
- 工具条「提取文字」或 `F4` 框选，Windows 本地 OCR 引擎，语言跟随系统
- 结果窗：可编辑、合并段落清理排版、重新识别、一键复制
- 识别后可自动复制；语言包缺失时给出引导提示

### 系统与体验
- **贴图**：置顶、拖动/缩放/旋转/透明度、再取字（`Ctrl+T`）、再标注（`Ctrl+E`）
- **拖拽导出**：覆盖层 `Ctrl+拖拽选区`、贴图 `Ctrl+拖拽`、历史缩略图拖到
  资源管理器/微信/Word
- 主题：浅色 / 深色 / 跟随系统；单实例；开机自启；便携模式
- 设置实时生效、`QSettings` 持久化（损坏回退）；本地日志（轮转、级别）
- **英文界面**（119 条文案，设置切到 English 后重启生效）
- 崩溃日志、资源稳定性自检、性能自检
