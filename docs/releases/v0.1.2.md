# SnapOCR 0.1.2（补丁版）

> 发布日期：2026-10-26
> 对比版本：v0.1.1
> 下载：[SnapOCR-0.1.2-win64.zip](https://github.com/poluce/SnapOCR/releases/download/v0.1.2/SnapOCR-0.1.2-win64.zip)

## 新增

### 贴图可再取字 / 再标注（补 F-ANN-19 验收）
- 贴图右键「提取文字」(Ctrl+T)：贴图直接交给 OCR，无需重新框选
- 贴图右键「在编辑器中打开」(Ctrl+E)：贴图作为底图进入标注编辑器，
  `Enter` 复制、`Ctrl+S` 保存、`Esc` 关闭；编辑完可继续贴/存

### 界面英文翻译覆盖到 119 条
- 设置面板、截图历史、OCR 结果窗、滚动长截图控制条、贴图菜单、托盘菜单、
  主窗口、标题栏，以及托盘气泡/状态栏/错误提示等 119 条文案全部英文可用
- 设置「界面语言」切到 English 后重启生效
- 新增 `scripts/gen_translations.py`：规范化 .ts 的 context 并校验缺词

## 修复

- 发布包缺 `translations/snapocr_en.qm`，导致英文界面在分发包不生效
  （CI 与 `package.bat` 均已补上翻译复制）
