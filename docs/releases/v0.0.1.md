## SnapOCR v0.0.1

Windows 上的免费截图 + 标注 + 文字识别工具，绿色免安装、全程离线。

### 主要功能

**截图（F1）**
- 全局热键唤起，冻结画面后框选
- 拖动 / 8 向控制点缩放 / 方向键微调（1px，Shift 10px）
- 实时显示尺寸与坐标，物理像素 1:1 输出（支持 100%–200% 缩放）
- 全屏截图 `Ctrl+A`，`Enter`/双击确认，`Esc`/右键取消

**标注**
- 矩形、椭圆、直线、箭头、画笔、文字、序号、高亮、马赛克（9 类）
- 选中 / 移动 / 删除，撤销重做（100 步）
- 颜色、线宽、字号可调；导出按物理像素 1:1 渲染

**文字识别（F4）**
- 框选屏幕区域直接取字，默认自动复制到剪贴板
- 结果窗显示识别语言与耗时，可编辑修正、复制、重新识别
- 使用系统内置 Windows OCR，完全离线；大图自动切片识别

**输出**
- `Enter`/`Ctrl+C` 复制到剪贴板（PNG + DIB，兼容 QQ/微信/Office）
- `Ctrl+S` 按模板保存 PNG/JPG，同名自动加序号

**系统集成**
- 托盘常驻菜单（截图 / 取字 / 打开主窗口 / 设置 / 退出）
- 热键可配置，冲突检测并给出回退提示
- 单实例：重复启动会唤起已有实例
- 设置持久化（热键 / 保存目录 / 格式 / 文件名模板 / 主题 / 开机自启 / OCR 自动复制 / 日志级别）
- 浅色 / 深色 / 跟随系统主题，本地日志轮转

### 安装

1. 下载 `SnapOCR-0.0.1-win64.zip`
2. 解压到任意目录（如 `D:\Tools\SnapOCR`）
3. 双击 `SnapOCR.exe`

免安装、免管理员权限、默认不联网。配置在 `%APPDATA%\SnapOCR\SnapOCR.ini`，日志在 `%LOCALAPPDATA%\poluce\SnapOCR\logs`。

### 系统要求

- Windows 10 1903+ / Windows 11，x64
- 文字识别需要系统安装 OCR 语言包（Windows 设置 → 时间和语言 → 语言 → 对应语言的“光学字符识别”可选功能）

### 验证

- 单元测试 13/13 通过（坐标换算 / 选区 / 裁剪 / 标注 / 画布交互 / 热键 / 设置 / 自启 / OCR 服务 / 文本整理 / 冒烟）

- 移除 Qt 环境变量后运行包内 exe：`--version` 输出 `SnapOCR 0.0.1`，`--smoke-test` PASS

### 已知限制

- 多显示器 + 混合 DPI 场景未在双屏实机验证（代码与坐标单测已覆盖），欢迎反馈
- Windows 内置 OCR 中文准确率一般，复杂排版/小字可能有错字（计划后续接入离线 OCR 引擎改善）
- 全屏独占游戏 / DRM 受保护画面无法捕获
- 进入标注编辑时选区外显示实时桌面（非冻结暗化）
